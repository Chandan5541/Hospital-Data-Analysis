# Hospital Data Analysis (SQL)

SQL analysis of a hospital dataset to answer business questions about patients, stays and expenses.

## Business questions answered
- Total number of patients across all hospitals
- Average number of doctors per hospital
- Top 3 departments by number of patients
- Hospital with the highest medical expenses
- Daily average medical expenses per hospital
- Patient with the longest hospital stay
- Total patients treated per city
- Average length of stay per department
- Department with the lowest number of patients
- Monthly medical expenses report

## SQL concepts used
SUM, AVG, GROUP BY, ORDER BY, LIMIT, date functions (date difference, TO_CHAR for monthly grouping)

## Tools
PostgreSQL
